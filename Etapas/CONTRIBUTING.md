# Contribuição e organização

1. Crie uma branch: `git switch -c docs/nova-anotacao`.
2. Faça alterações pequenas e relacionadas ao mesmo assunto.
3. Documente o conteúdo e cite fontes quando necessário.
4. Confira links e ortografia; teste o site localmente se alterar `docs/`.
5. Faça commit descritivo (`feat:`, `fix:`, `docs:`, `style:`, `refactor:`).
6. Envie a branch e abra um Pull Request, se desejar revisar antes de integrar.

Nunca publique senhas, tokens, documentos privados ou certificados com dados sensíveis.
