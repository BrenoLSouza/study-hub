# Study Hub — Site institucional

## 1. Objetivo
Construir uma apresentação pública do portfólio acadêmico e profissional.

## 2. Solução
Site estático responsivo com HTML, CSS e JavaScript, armazenado em `../../../docs/` e publicado pelo GitHub Pages.

## 3. Desenvolvimento
Arquitetura sem build e sem dependências externas; navegação por seções, filtros de disciplinas e projetos, tema claro/escuro e configuração central de links.

## 4. Testes
Teste manual local: abrir `docs/index.html` via servidor HTTP, conferir menu, filtros, links, responsividade e tema. A publicação pública deve ser validada após o deploy.

## 5. Resultados
Código inicial e documentação preparados para versionamento e publicação. **Deploy e histórico remoto dependem da execução dos passos no GitHub.**
