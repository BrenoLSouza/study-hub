# Site público (GitHub Pages)

Esta pasta é a **raiz do website**. Em GitHub → Settings → Pages, selecione `Deploy from a branch`, `main` e **`/docs`**.

- `index.html`: conteúdo e estrutura da página.
- `assets/css/styles.css`: identidade visual e responsividade.
- `assets/js/config.js`: nome de usuário GitHub, LinkedIn e e-mail.
- `assets/js/main.js`: menu mobile, filtros, tema e links.
- `assets/img/favicon.svg`: ícone do site.
- `.nojekyll`: evita processamento desnecessário pelo Jekyll.
- `404.html`: página de erro.

Não é necessário instalar Node, npm, React ou gerador de site. Os links de GitHub só apontarão para o seu repositório após editar `config.js`.
