# Certificados e competências

Áreas: programação, engenharia de software, banco de dados, inteligência artificial e idiomas.

Adicione apenas certificados realmente obtidos. Para cada certificado, registre: nome, instituição emissora, data, carga horária (se disponível), habilidades relacionadas e link público de validação quando houver. Evite publicar documentos com dados pessoais desnecessários.
