# Checklist da entrega intermediária

- [ ] Repositório público com README principal
- [ ] Pastas organizadas por projeto/área
- [ ] Um projeto demonstrável (website em `docs/`)
- [ ] Commits visíveis no histórico do GitHub
- [ ] Tag `v1.0.0` criada após validação
- [ ] Site publicado pelo GitHub Pages a partir de `main` e `/docs`
- [ ] README próprio nos projetos apresentados
- [ ] GitHub e site adicionados ao LinkedIn
- [ ] Vídeo de apresentação de até 5 minutos gravado
- [ ] Links públicos conferidos e enviados na plataforma da disciplina

**Atenção:** criar os arquivos localmente não significa que as etapas online foram concluídas.
